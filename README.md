# Диалоговый помощник с векторной памятью

Telegram-бот, который ведёт диалог и хранит факты о пользователе в [Pinecone](https://www.pinecone.io/). Перед записью сравнивает новое сообщение с уже сохранёнными векторами (косинусное сходство): новая информация добавляется, похожая формулировка обновляет существующий слот.

## Как это устроено

1. Пользователь пишет в Telegram.
2. Бот ищет в Pinecone похожие фразы **этого** человека (`namespace=user_<telegram_id>`).
3. Ответ модели строится с учётом найденной памяти и короткого контекста текущей сессии.
4. В индекс уходит **исходный текст** сообщения, не ответ бота и не шаблонные пересказы.
5. Эмбеддинги считаются через OpenAI-совместимый API (в том числе через прокси `OPENAI_BASE_URL`).

При сходстве ниже порога `COSINE_SIMILARITY_THRESHOLD` (по умолчанию `0.5`) создаётся новая запись (`inserted`). При сходстве выше или равном порогу обновляется найденный слот (`updated`).

## Состав проекта

| Файл | Назначение |
|---|---|
| `bot.py` | Telegram-бот (`pyTelegramBotAPI`) |
| `pinecone_manager.py` | Работа с Pinecone: запись, поиск, удаление, проверка дубликатов |
| `.env_example` | Список переменных окружения |
| `requirements.txt` | Зависимости Python |

Команды бота: `/start` — приветствие, `/forget` — стереть память текущего пользователя.

## Окружение

Нужны Python 3.11+, индекс Pinecone (dense, размерность **1536**, метрика **cosine**), ключ OpenAI-совместимого API и токен Telegram-бота.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r .\requirements.txt
```

Скопируйте `.env_example` в `.env` и заполните:

- `PINECONE_API_KEY`, `PINECONE_INDEX_NAME`
- `OPENAI_API_KEY`, `OPENAI_BASE_URL` (адрес прокси к моделям, не `api.openai.com`)
- `TELEGRAM_TOKEN`

Опционально: `TELEGRAM_PROXY`, если до `api.telegram.org` нет стабильного доступа.

Секреты хранятся только в `.env` и в git не попадают.

## Запуск бота

В активированном `.venv`:

```powershell
python bot.py
```

Держите процесс в одном терминале. Второй экземпляр даст двойные ответы в Telegram.

В этом же терминале пишутся строки памяти, например:

```
memory: action=inserted similarity=None text='Привет'
memory: action=updated similarity=0.79 text='Я полечу на Марс'
```

## Проверка памяти без Telegram

`pinecone_manager.py` можно запустить отдельно. Скрипт подключается к индексу, пишет тестовый факт, затем похожую фразу (ожидается `updated`), делает поиск и очищает тестовый namespace `manual_test`.

```powershell
python pinecone_manager.py
```

Запускайте в отдельном терминале с активированным `.venv`, пока бот остановлен или в другом окне. Это удобно, чтобы смотреть `action` и коэффициент сходства в логе, не открывая Telegram.

## Индекс Pinecone

Имя индекса должно совпадать с `PINECONE_INDEX_NAME`. Модель эмбеддингов по умолчанию — `text-embedding-3-small` (1536 измерений). Память пользователей разделена по namespace, записи одного человека не смешиваются с другими.
